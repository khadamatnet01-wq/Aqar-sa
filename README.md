# عقار (Aqar.fm) - أكتور سحب الإعلانات العقارية

أكتور Apify مخصّص لاستخراج إعلانات العقارات من موقع **عقار السعودي** (sa.aqar.fm).

---

## الاستراتيجية

1. **صفحة القائمة** — تحتوي كل البيانات الأساسية مباشرة في الـ HTML: العنوان، السعر، المساحة، الحي، الوصف الكامل، وأحياناً الجوال نفسه إن كان مكتوباً صراحة في الوصف.
2. **صفحة التفاصيل** — تُفتح فقط للإعلانات التي **لم يظهر جوالها** في القائمة، وتحاول الضغط تلقائياً على زر "اتصال" لكشف الرقم المحجوب بجافاسكريبت، بالإضافة لاستخراج تاريخ النشر.

---

## الحقول المُستخرجة

| الحقل | الوصف |
|---|---|
| `name` | عنوان الإعلان الكامل |
| `priceSar` | السعر بالريال |
| `listing_type` | بيع أو إيجار |
| `property_type` | نوع العقار (شقة، فيلا، أرض...) |
| `city` | المدينة |
| `district` | الحي |
| `area_sqm` | المساحة بالمتر المربع |
| `bedrooms` / `bathrooms` | الغرف ودورات المياه (من صفحة التفاصيل) |
| `phone` | رقم الجوال |
| `owner_name` | اسم المعلن |
| `rega_license` | رخصة فال / رقم الترخيص |
| `is_verified` | هل الإعلان موثّق؟ |
| `posted_at` / `posted_at_iso` | تاريخ النشر |
| `scanned_at` | وقت فحص الإعلان |
| `description` | نص الوصف الكامل |
| `images` | روابط الصور |
| `url` | رابط الإعلان |

---

## مثال على الإدخال

```json
{
    "search": "شقق-للبيع",
    "city": "الرياض",
    "maxResults": 50,
    "fetchPhoneFromDetail": true
}
```

**أنواع بحث شائعة:** `شقق-للبيع`، `شقق-للإيجار`، `فلل-للبيع`، `فلل-للإيجار`، `أراضي-للبيع`، `دور-للبيع`، `عمائر-للبيع`، `محلات-للإيجار`

---

## ملاحظات

- الجوال في عقار غالباً **محجوب بجافاسكريبت** خلف زر "اتصال" — الأكتور يحاول الضغط عليه تلقائياً لكشفه.
- تعطيل `fetchPhoneFromDetail` يجعل السحب أسرع بكثير لكن دون ضمان جلب كل أرقام الجوال.
- يُنصح باستخدام **Residential Proxy** لتجنب الحجب.
